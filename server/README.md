# MedHire Transparency

A full-stack platform for transparent healthcare hiring in Uzbekistan.

## Setup

1. Install dependencies:
   - Server: `cd server && npm install`
   - Client: `cd client && npm install`

2. Seed database: `cd server && node seed.js`

3. Start server: `cd server && node index.js`

4. Start client: `cd client && npm start`

## Demo Accounts

- Admin: admin@medhire.uz / password
- Hospital Admin: hospital@medhire.uz / password

## Features

- User registration with mock face ID
- Document verification
- Vacancy posting
- Application submission
- Scoring system
- Complaint system
- Transparency dashboard
